# Agent working documentation

Stage directories carry the forecast, its inputs and the full model specification. Use this index for shared standards, collection operations and completed research. [Project guide](../../AGENTS.md) · [Published forecasts](../../README.md)

## Task routing

| Task | Read |
|---|---|
| Choose data sources and review coverage | [Collection plan](data/collection-plan.md) |
| Run collection, cached replay, validation, restoration or export | [Data runbook](data/runbook.md) |
| Interpret IDs, timestamps, ratings and provenance | [Data contract](data/contract.md) |
| Use the Singapore Stage 1 settings and run commands | [Stage 1 model](../../2026_singapore/stage1/model.md) |
| Design or evaluate a forecast across stages | [Modeling guide](modeling.md) |
| Review completed Singapore Stage 1 comparisons | [Stage 1 findings](research/singapore_stage1_findings_2026-11-24.md) |
| Compare the Singapore Stage 1 picks with the results and historical cross-region LAN matches | [Stage 1 retrospective](research/singapore_stage1_review_2026-11-28.md) |
| Check HLTV access, historical coverage and rating semantics | [Source validation](research/hltv_collection_2026-10-20.md) · [Coverage audit](research/collection_history_2026-10-22.md) · [Rating comparison](research/ratings_comparison_2026-10-20.md) |

Use the runbook for commands, the contract for field semantics, and the collection plan for source choices. Record completed experiments with their comparison, scope and outcome. Keep operational evidence in `data/reports/` and raw diagnostics in `data/raw/diagnostics/`.

# CS2 Major 通行证竞猜预测

用比赛数据、概率模型和赛事模拟，研究怎样填写 CS2 Major Pick'Em，才能提高通行证竞猜过关的概率。

当前正在准备新加坡 Major 的数据与模型，尚未发布各阶段预测。参赛队、注册阵容、种子和竞猜规则确认后，再生成对应阶段的方案。

## 大概的方法

1. **整理比赛记录。** 保存赛果、地图比分、BP 和实际出场阵容，以固定的数据快照支持每次预测。
2. **估计对战胜率。** 先建立队伍实力与地图表现的基线，再通过历史回测判断阵容变化、选手状态与稳定性是否带来额外帮助。
3. **验证概率是否可信。** 按时间划分训练与验证数据，检查预测误差和概率校准，避免仅凭几个预测成功的案例挑选算法。
4. **模拟整个阶段。** 根据当届赛制模拟 BP、比赛与配对，保留不同队伍结果之间的关联。
5. **选择竞猜组合。** 以达到竞猜过关分数的概率为主要目标；单场命中率、期望得分和选中最多强队都不能直接替代这个目标。

历史算法和参数只是参考，新模型是否采用它们，要由验证结果决定。每个阶段的结果页会集中展示推荐填写方式、模型估计的过关率、队伍 BP 总结、对战胜率表及赛后复盘。

## 项目结构

```text
data/                  跨 Major 共享的数据与采集工具
  pipeline/            采集、标准化、校验和导出代码
  datasets/            按来源和月份保存、由 Git 共享的 JSONL 数据
  raw/                 本地原始响应与缓存
  processed/           本地采集工作库 history.sqlite3
  snapshots/           各次预测引用的本地固定数据快照
  reports/             数据质量与运行记录
2026_singapore/        新加坡赛事配置与后续阶段预测
2026_cologne/          保留的历史预测与代码
docs/Agent/            Agent 工作所需的采集说明、研究与设计资料
AGENTS.md              Agent 文档入口和项目约定
```

规范数据保存在 `data/datasets/` 并随 Git 共享，分析环境可直接读取；原始响应、SQLite 工作库和阶段快照保存在本地。采集操作与算法研究细节由 Agent 工作文档维护；需要讨论某个设计时，再单独整理面向人的说明。

这是一个个人预测项目，结构和工具以当前需要为准，主要精力放在数据质量、模型验证和竞猜过关率上。有实际需求时再扩展。
